## Overview

This document covers two important aspects of apimachinery: the conversion system for transforming objects between API versions, and the resource quantity system for representing computational resources.

## Conversion Package

### Purpose

The `pkg/conversion` package provides automatic and manual conversion between different versions of API objects. It enables Kubernetes to maintain backward compatibility while evolving its APIs.

### Architecture

![Diagram](/diagrams/diagram-b0699fba.svg)

### Converter

The core conversion engine:

```go
type Converter struct {
    conversionFuncs          ConversionFuncs
    generatedConversionFuncs ConversionFuncs
    ignoredUntypedConversions map[typePair]struct{}
}
```

### Creating a Converter

```go
import "k8s.io/apimachinery/pkg/conversion"

converter := conversion.NewConverter(nil)
```

### Conversion Functions

#### Function Signature

```go
type ConversionFunc func(a, b interface{}, scope Scope) error
```

**Parameters:**
- `a`: Source object (input)
- `b`: Destination object (output, must be pointer)
- `scope`: Conversion scope for recursive conversions

#### Registering Conversions

```go
// Register conversion function
err := converter.RegisterUntypedConversionFunc(
    (*v1.Pod)(nil),
    (*core.Pod)(nil),
    func(a, b interface{}, scope conversion.Scope) error {
        return Convert_v1_Pod_To_core_Pod(
            a.(*v1.Pod),
            b.(*core.Pod),
            scope,
        )
    },
)
```

### Conversion Scope

Allows recursive conversions:

```go
type Scope interface {
    // Convert sub-objects
    Convert(src, dest interface{}) error
    
    // Get metadata
    Meta() *Meta
}
```

**Usage:**

```go
func Convert_v1_Pod_To_core_Pod(in *v1.Pod, out *core.Pod, s conversion.Scope) error {
    // Direct field copy
    out.Name = in.Name
    out.Namespace = in.Namespace
    
    // Recursive conversion of nested objects
    if err := s.Convert(&in.Spec, &out.Spec, 0); err != nil {
        return err
    }
    
    return nil
}
```

### Auto-generated Conversions

Code generators create conversion functions:

```go
// Auto-generated by conversion-gen
func autoConvert_v1_Pod_To_core_Pod(in *v1.Pod, out *core.Pod, s conversion.Scope) error {
    out.ObjectMeta = in.ObjectMeta
    if err := Convert_v1_PodSpec_To_core_PodSpec(&in.Spec, &out.Spec, s); err != nil {
        return err
    }
    if err := Convert_v1_PodStatus_To_core_PodStatus(&in.Status, &out.Status, s); err != nil {
        return err
    }
    return nil
}
```

### Manual Conversion Overrides

Override auto-generated conversions for complex cases:

```go
// Manual conversion that calls auto-generated version
func Convert_v1_Pod_To_core_Pod(in *v1.Pod, out *core.Pod, s conversion.Scope) error {
    // Call auto-generated conversion
    if err := autoConvert_v1_Pod_To_core_Pod(in, out, s); err != nil {
        return err
    }
    
    // Custom logic for fields that need special handling
    if in.Spec.ServiceAccountName == "" {
        out.Spec.ServiceAccountName = "default"
    }
    
    return nil
}
```

### Deep Copy

Create deep copies of objects:

```go
// Deep copy using conversion
func DeepCopy(obj interface{}) (interface{}, error) {
    // Create new instance of same type
    typ := reflect.TypeOf(obj)
    if typ.Kind() == reflect.Ptr {
        typ = typ.Elem()
    }
    
    copy := reflect.New(typ).Interface()
    
    // Convert to self (creates deep copy)
    err := converter.Convert(obj, copy, nil)
    return copy, err
}
```

### Conversion Patterns

#### Hub-and-Spoke

All versions convert through internal version:

![Diagram](/diagrams/diagram-15dec0f7.svg)

**Benefits:**
- O(N) conversion functions instead of O(N²)
- Single source of truth
- Easier to maintain

#### Lossless Conversion

Conversions must be round-trip safe:

```go
// v1 -> internal -> v1 should be lossless
original := &v1.Pod{...}
internal := &core.Pod{}
roundtrip := &v1.Pod{}

converter.Convert(original, internal, nil)
converter.Convert(internal, roundtrip, nil)

// original and roundtrip should be equal
```

### Conversion Metadata

Pass context through conversions:

```go
type Meta struct {
    Context interface{}
}

// Use in conversion
func Convert_v1_Pod_To_core_Pod(in *v1.Pod, out *core.Pod, s conversion.Scope) error {
    meta := s.Meta()
    if meta.Context != nil {
        // Use context information
    }
    return nil
}
```

## Resource Package

### Purpose

The `pkg/api/resource` package provides the `Quantity` type for representing computational resources like CPU, memory, and storage with precise decimal arithmetic.

### Quantity Type

Fixed-point decimal representation:

```go
type Quantity struct {
    // Internal representation
    i     int64Amount
    d     infDecAmount
    s     string
    Format Format
}
```

### Creating Quantities

```go
import "k8s.io/apimachinery/pkg/api/resource"

// From string
cpu := resource.MustParse("500m")      // 500 millicores
memory := resource.MustParse("128Mi")  // 128 mebibytes
storage := resource.MustParse("10Gi")  // 10 gibibytes

// From int64
cpu := resource.NewQuantity(2, resource.DecimalSI)  // 2 cores
memory := resource.NewQuantity(1024*1024*1024, resource.BinarySI)  // 1Gi

// From millis
cpu := resource.NewMilliQuantity(500, resource.DecimalSI)  // 500m
```

### Quantity Formats

#### Decimal SI (Base 10)

```go
const (
    Nano  = 1e-9   // n
    Micro = 1e-6   // u
    Milli = 1e-3   // m
    Kilo  = 1e3    // k
    Mega  = 1e6    // M
    Giga  = 1e9    // G
    Tera  = 1e12   // T
    Peta  = 1e15   // P
    Exa   = 1e18   // E
)
```

**Examples:**
- `100m` = 0.1 (100 millicores)
- `1k` = 1000
- `1M` = 1,000,000
- `1G` = 1,000,000,000

#### Binary SI (Base 2)

```go
const (
    Ki = 1024      // Kibi
    Mi = 1024^2    // Mebi
    Gi = 1024^3    // Gibi
    Ti = 1024^4    // Tebi
    Pi = 1024^5    // Pebi
    Ei = 1024^6    // Exbi
)
```

**Examples:**
- `128Mi` = 134,217,728 bytes
- `1Gi` = 1,073,741,824 bytes
- `1Ti` = 1,099,511,627,776 bytes

#### Decimal Exponent

```go
// Scientific notation
"1e3"  = 1000
"1e6"  = 1,000,000
"1.5e3" = 1500
```

### Quantity Operations

#### Comparison

```go
q1 := resource.MustParse("1Gi")
q2 := resource.MustParse("1024Mi")

// Compare
cmp := q1.Cmp(q2)
// cmp == 0 (equal)
// cmp < 0 (q1 < q2)
// cmp > 0 (q1 > q2)

// Equality
if q1.Equal(q2) {
    fmt.Println("Equal")
}
```

#### Arithmetic

```go
q1 := resource.MustParse("1Gi")
q2 := resource.MustParse("512Mi")

// Add
q1.Add(q2)  // q1 = 1.5Gi

// Subtract
q1.Sub(q2)  // q1 = 0.5Gi

// Negate
q1.Neg()    // q1 = -0.5Gi
```

#### Conversion

```go
q := resource.MustParse("1Gi")

// To int64 (may lose precision)
value := q.Value()  // 1073741824

// To milli (for CPU)
millis := q.MilliValue()  // 1073741824000

// To float64 (may lose precision)
float := q.AsApproximateFloat64()

// To string
str := q.String()  // "1Gi"
```

#### Scaling

```go
q := resource.MustParse("1Gi")

// Scale by integer
q.SetScaled(512, resource.Mega)  // 512M

// Scale by float
q.SetMilli(500)  // 500m
```

### Canonical Form

Quantities are normalized to canonical form:

```go
// These are equivalent and normalize to same form
q1 := resource.MustParse("1000m")
q2 := resource.MustParse("1")
q3 := resource.MustParse("1000000u")

// All serialize as "1"
```

**Rules:**
1. No precision loss
2. No fractional digits
3. Exponent as large as possible
4. Sign omitted unless negative

### Resource Lists

Map of resource names to quantities:

```go
type ResourceList map[ResourceName]Quantity

// Create resource list
resources := v1.ResourceList{
    v1.ResourceCPU:    resource.MustParse("500m"),
    v1.ResourceMemory: resource.MustParse("128Mi"),
}

// Access
cpu := resources[v1.ResourceCPU]
memory := resources[v1.ResourceMemory]
```

### Resource Names

Standard resource names:

```go
const (
    ResourceCPU              ResourceName = "cpu"
    ResourceMemory           ResourceName = "memory"
    ResourceStorage          ResourceName = "storage"
    ResourceEphemeralStorage ResourceName = "ephemeral-storage"
    ResourcePods             ResourceName = "pods"
)
```

### Use Cases

#### Pod Resource Requirements

```go
pod := &v1.Pod{
    Spec: v1.PodSpec{
        Containers: []v1.Container{
            {
                Name: "app",
                Resources: v1.ResourceRequirements{
                    Requests: v1.ResourceList{
                        v1.ResourceCPU:    resource.MustParse("100m"),
                        v1.ResourceMemory: resource.MustParse("128Mi"),
                    },
                    Limits: v1.ResourceList{
                        v1.ResourceCPU:    resource.MustParse("500m"),
                        v1.ResourceMemory: resource.MustParse("512Mi"),
                    },
                },
            },
        },
    },
}
```

#### Persistent Volume Claims

```go
pvc := &v1.PersistentVolumeClaim{
    Spec: v1.PersistentVolumeClaimSpec{
        Resources: v1.ResourceRequirements{
            Requests: v1.ResourceList{
                v1.ResourceStorage: resource.MustParse("10Gi"),
            },

```

#### Resource Quotas

```go
quota := &v1.ResourceQuota{
    Spec: v1.ResourceQuotaSpec{
        Hard: v1.ResourceList{
            v1.ResourceCPU:    resource.MustParse("10"),
            v1.ResourceMemory: resource.MustParse("10Gi"),

    },
}
```

### Precision and Limits

**Precision:**
- Up to 3 decimal places
- Uses arbitrary precision arithmetic internally
- Rounded when necessary

**Limits:**
- Maximum value: 2^63-1 in base units
- Minimum value: -(2^63-1)

**Examples:**

```go
// Valid
resource.MustParse("999999999999999999")  // Large value
resource.MustParse("0.001")               // Small value
resource.MustParse("1.234")               // Decimal

// Precision loss (rounded)
resource.MustParse("0.0001")  // Becomes "0"
resource.MustParse("1.2345")  // Becomes "1.235"
```

### Parsing and Validation

```go
// Parse with error handling
q, err := resource.ParseQuantity("invalid")
if err != nil {
    fmt.Println("Invalid quantity:", err)
}

// Must parse (panics on error)
q := resource.MustParse("1Gi")

// Validate format
if err := validateQuantity("1Gi"); err != nil {
    fmt.Println("Invalid:", err)
}
```

## Summary

### Conversion System

1. **Converter**: Core conversion engine
2. **Hub-and-Spoke**: All versions convert through internal
3. **Auto-generated**: Most conversions are generated
4. **Manual Overrides**: Complex cases need manual functions
5. **Lossless**: Round-trip conversions preserve data
6. **Deep Copy**: Create copies via self-conversion

### Resource Quantities

1. **Fixed-Point**: Precise decimal arithmetic
2. **Multiple Formats**: Decimal SI, Binary SI, Exponent
3. **Canonical Form**: Normalized representation
4. **Arithmetic**: Add, subtract, compare operations
5. **Resource Lists**: Map of resource names to quantities
6. **Use Cases**: CPU, memory, storage specifications

These systems are fundamental to Kubernetes' ability to evolve its APIs while maintaining backward compatibility and to precisely represent computational resources.
